# Интеграция по доступным данным

Парсер построен по локальному RADMIR chatlog, найденному в папке документов пользователя. Подтверждённые формы записей:

- Входящее обращение: `[HH:MM:SS] [RADMIR] Имя[ID игрока]: текст`.
- Вариант FAQ: цветовые коды, `[FAQ]`, затем `[RADMIR] Имя[ID игрока]: текст`.
- Ответ администратора или агента поддержки: `... Администратор Имя[ID]: ... для Игрок[ID]: ...` либо `... Агент поддержки Имя[ID]: ... для Игрок[ID]: ...`.
- Блокировка репортов: `... Администратор Имя[ID] заблокировал репорт игроку Имя[ID] на ... мин. Причина: ...`.

Отдельный серверный ID репорта и дата в записи обращения отсутствуют. Панель поэтому выдаёт устойчивый локальный номер, отдельно хранит ID игрока и отображает исходное время `HH:MM:SS`.

Команда `/sp` упоминается в логе как подсказка использовать `/spinfo`; работающий процесс игры и его окно во время проверки отсутствовали. Доступный модуль `ClipboardGameIntegration` готовит `/sp <ID игрока>` и копирует команду в буфер обмена. Автоматическая отправка клавиш или внедрение кода в игру не включены.

Формат новых записей и статусов из других источников не предполагается. Для Hassle 2.0 потребуется отдельный `IReportSource`, подключённый к подтверждённому игровому интерфейсу.
