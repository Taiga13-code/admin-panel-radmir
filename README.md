# ReportPanel

ASI-плагин с внутриигровой панелью отчётов и жалоб для GTA San Andreas.  
Панель отображается поверх игры, читает игровой chatlog, хранит отчёты локально и позволяет отправлять команды в игровой чат через буфер обмена.

## Установка

1. Установите ASI Loader для игры.
2. Поместите файл `ReportPanel.asi` в корневую папку игры — рядом с `gta_sa.exe`.
3. Запустите игру.

Настройки и отчёты создаются плагином автоматически при первом запуске.
