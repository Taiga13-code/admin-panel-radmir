# ReportPanel ASI

Внутриигровая панель репортов для RADMIR RP на C++20, Dear ImGui и Direct3D 9. Сборка создаёт `ReportPanel.asi`, который загружается ASI-загрузчиком в процесс игры; отдельного окна поверх GTA нет.

## Сборка

Нужны CMake 3.24+, Visual Studio 2022 C++ Build Tools и Windows SDK. RADMIR CRMP/GTA San Andreas — 32-битное приложение, поэтому сборка задаёт платформу Win32.

Запусти `build.bat` либо `build.ps1`. Результат: `build-asi/Release/ReportPanel.asi`.

Скопируй `ReportPanel.asi` в папку игры, рядом с исполняемым файлом и установленным ASI-загрузчиком. Разрядность загрузчика и плагина должна совпадать с игрой. Плагин перехватывает D3D9 `EndScene`/`Reset` через MinHook и рисует ImGui в игровом кадре. Панель стартует скрытой; F11 показывает и скрывает её. Окно можно перетаскивать и менять в размере, положение и размеры сохраняются.

## Источник репортов

Читатель следит за добавлением строк в chatlog в отдельном потоке. Парсер распознаёт предоставленные префиксы `[RADMIR]`, `[HASSLE]` и `[FAQ]`, в том числе цветные теги перед ними. ID в скобках — игровой ID автора, отдельного серверного ID репорта в примерах нет; интерфейс присваивает записи локальный последовательный номер.

Путь к chatlog настраивается в панели. По умолчанию используется `%USERPROFILE%\Documents\RADMIR CRMP User Files\SAMP\chatlog.txt`. Состояние и настройки сохраняются в `%LOCALAPPDATA%\ReportPanel`. При повторном запуске читатель восстанавливает последние 15 минут строк, если heartbeat игры не старше 15 минут; это возвращает репорты после краша и не проигрывает старую историю после истечения срока хранения. Данные репортов очищаются при следующем запуске, если с последнего heartbeat прошло больше 15 минут.

Кнопка «Следить» отправляет `/sp <ID игрока>` и закрывает панель. Кнопка «Ответить» открывает поле сообщения и отправляет `/pm <ID игрока> <текст>`, оставляя панель открытой. Обе команды отправляются через отдельный игровой модуль: он открывает чат клавишей `T`, вставляет команду и подтверждает её. Нажимать `T` для показа курсора не нужно: курсор включается отдельно, а обычные клавиши и клики во время открытого меню не передаются игре.

Счётчик ответов сравнивает ник администратора с форматом строк `Администратор <ник>[ID] для <игрок>[ID]: ...`; такой пример предоставлен для chatlog. Введи точное `Имя_Фамилия` в настройках и нажми «Сохранить ник». При изменении ника программа повторно проверяет строки последних 15 минут; повторные события не учитываются дважды.

## Архитектура и ограничения

`core`, `parser`, `chatlog`, `settings`, `themes` и интерфейсы источника/игрового действия не зависят от рендерера. Для Hassle 2.0 источник данных не добавлен, так как способ получения репортов пока неизвестен.

Это первая ASI-сборка. Её совместимость зависит от конкретной версии игры, D3D9, ASI-загрузчика и других модулей, которые могут перехватывать оконную процедуру или Direct3D. Если игра или сервер запрещают сторонние плагины, не устанавливай её туда.
